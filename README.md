# SHA STEELS Website

Static, bilingual (English / Malayalam) website for SHA STEELS, a supplier of TMT steel bars, cement and steel tubes in Kerala, India. No backend, no build step, no package manager.

## 1. Overview

Pages: `index.html` (Home), `products.html`, `about.html`, `contact.html` (quotation form + map), `404.html`.
Customers browse brands, click **Request Price** (opens the contact page with the brand preselected) and the form builds a WhatsApp message they review and send.

## 2. Local testing

```bash
cd sha-steels
python3 -m http.server 8080
# open http://localhost:8080
```
Any static server works. Opening `index.html` directly also works for most features.

## 3. File structure

```
index.html  products.html  about.html  contact.html  404.html
css/style.css          layout and design tokens
js/config.js           OWNER SETTINGS (phone, WhatsApp, hours, map)
js/language.js         English + Malayalam dictionary
js/main.js             header/footer, nav, WhatsApp helper, product rendering
js/quotation.js        quotation form logic
data/products.js       brand catalogue
assets/images/*.svg    local illustrations
favicon.svg  robots.txt  sitemap.xml
```

## 4. Update business details

Edit **`js/config.js`** only:
- `PHONES` - list of `{ display, tel }` numbers shown on the Contact page and footer
- `OPENING_HOURS` - free text
- `SITE_URL` - final site address (for your reference; also update `sitemap.xml` and `robots.txt`)

Anything left empty shows "Awaiting confirmation from the business" or is hidden. No placeholder numbers are ever shown.

## 5. Configure the WhatsApp number

In `js/config.js` set `WHATSAPP_NUMBER` to the number in international format, digits only, no `+`, no spaces. Example: `"919812345678"`.
Until set: WhatsApp buttons and the floating button are hidden, and the form tells customers enquiries cannot be sent yet.

## 6. Update product listings

Edit `data/products.js`. Add `{ name: "Brand Name", category: "tmt" | "cement" | "tubes", descKey: "prod.tmt.desc" }` to `brands`. The product page, home brand list, quotation dropdown and footer update automatically. Only brand names in this list are accepted from `?product=` URLs.
Do not add grades, sizes, prices or "authorised dealer" claims unless confirmed.

## 7. Edit translations

All text is in `js/language.js` under `en` and `ml`. Keep both languages in sync (same keys). Elements use `data-i18n="key"`. Have a Malayalam speaker proofread the Malayalam text before launch. Brand names are not translated.
The visitor's language choice is stored in `localStorage` (key `sha_lang`); no customer data is stored.

## 8. Deploy (free)

**Cloudflare Pages:** Dashboard -> Workers & Pages -> Create -> Pages -> Upload assets (drag the `sha-steels` folder) or connect a Git repo. Build command: none. Output directory: `/`. You get `https://<name>.pages.dev` with HTTPS; `404.html` is used automatically.

**GitHub Pages:** push the folder contents to a repo -> Settings -> Pages -> deploy from `main` / root. URL: `https://<user>.github.io/<repo>/`. For a project site, edit the `/`-prefixed paths in `404.html` to `/<repo>/`.

After deploying, open the live URL and verify: all pages, Malayalam toggle, map, Get Directions, WhatsApp (after setting the number). Then update `sitemap.xml`/`robots.txt` with the real URL and add `<link rel="canonical">` tags if desired.

## 9. Limitations

- Quotations are not submitted automatically. The form opens WhatsApp with a prefilled message; the customer must press Send.
- If a browser blocks the pop-up, a fallback link is shown.
- Illustrations are generic graphics, not photographs. Replace files in `assets/images/` (keep names or edit `data/products.js`) with the owner's own photos when available.
- The 404 page lives at root-relative paths; its header links work best on a domain root.
- Header/footer are generated by `js/main.js`; without JavaScript the pages show content but no menu.
- The Maps embed needs internet access and Google availability; fallback buttons are provided.
